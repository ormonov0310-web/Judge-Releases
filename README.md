# Judge для Android

Официальная страница загрузки приложения Judge — тестов для подготовки судей.

## Скачать последнюю версию

[Скачать Judge.apk](https://github.com/ormonov0310-web/Judge-Releases/releases/latest/download/Judge.apk)

Ссылка остаётся неизменной и после выхода обновлений всегда загружает последний
опубликованный APK.

> Первый пользовательский APK появится после создания постоянного release-ключа
> и проверки Google-входа с новой подписью. Debug-сборки здесь не публикуются.

## Установка

1. Откройте ссылку на Android-телефоне.
2. Дождитесь загрузки `Judge.apk`.
3. Откройте файл из уведомления браузера или папки «Загрузки».
4. Если Android попросит, разрешите этому браузеру установку неизвестных приложений.
5. Подтвердите установку.

Все обновления Judge будут подписываться одним постоянным ключом, поэтому новые
версии можно будет устанавливать поверх предыдущих без удаления приложения и
потери локальной статистики.

## Безопасность

- APK публикуется только в разделе **Releases** этого репозитория.
- Имя официального файла всегда `Judge.apk`.
- Для каждого выпуска в описании будет указан SHA-256 файла.
- Исходный код и ключ подписи в этом публичном репозитории не хранятся.
