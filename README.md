# JUDGE — Тест для судей

Один проект для Android и Windows. Тесты на русском и кыргызском языках,
сохранение прогресса и общий доступ при входе в один Google-аккаунт.

### Официальный общий тест

В Android и Windows общий тест имитирует официальный формат: 150 случайных
вопросов и 120 минут. Можно выбрать отрасли права и отключить таймер. Начатые
попытки сохраняются на устройстве: при выходе время ставится на паузу, а продолжение
возвращает к тому же вопросу и тому же случайному набору.

### Обновление внутри Judge

В новых версиях обновления можно скачать прямо в приложении:

- Android: «Настройки» → карточка обновления → «Обновить». Judge скачает и проверит
  APK, затем откроет системный установщик. При необходимости разрешите установку
  из Judge и подтвердите обновление. Когда новая версия доступна, карточка находится
  вверху настроек, а пункт «Настройки» мягко пульсирует.
- Windows: «Инфо» → «Скачать и установить» → «Обновить сейчас». Judge скачает и
  проверит обновление, закроется для установки и запустится снова.

Если в вашей старой версии этих кнопок ещё нет, один раз скачайте установщик по
ссылке выше и установите поверх. Не удаляйте приложение и не очищайте его данные.
Обычное обновление сохраняет аккаунт, прогресс, продолжение и настройки.

### Android

1. Скачайте `Judge.apk` на телефон и откройте файл из папки «Загрузки».
2. Если Android попросит, разрешите этому браузеру установку приложений из этого источника.
3. Подтвердите установку или обновление.

Не удаляйте прежнюю Judge и не очищайте её данные: устанавливайте новую версию
поверх. APK подписан тем же постоянным ключом и содержит миграцию прежнего прогресса.

### Windows

1. Скачайте и запустите `Judge-Setup.exe`.
2. Пройдите установку. Ярлык Judge появится на рабочем столе.
3. Откройте Judge, нажмите «Войти через Google» и завершите вход в браузере.

Отдельно устанавливать средства разработки не нужно. При отсутствии Microsoft
WebView2 установщик загрузит необходимый компонент; для этого нужен интернет.
Windows-установщик пока не имеет цифровой подписи издателя: Windows или браузер
могут показать предупреждение о неизвестном приложении. Это не требование
отключать защиту компьютера. На управляемых рабочих ПК установка может требовать
разрешения администратора организации.

### Один аккаунт на телефоне и ПК

Используйте один и тот же Google-аккаунт. Для первого входа и синхронизации нужен
интернет. Перед переносом прогресса со старой Android-версии сначала обновите её
поверх и откройте с интернетом. После синхронизации тот же прогресс доступен на ПК.
Для офлайн-работы программа хранит вопросы, прогресс и подтверждённый доступ;
временный доступ заканчивается по сохранённой дате.

## Безопасность файлов

- Официальные имена файлов: `Judge.apk` и `Judge-Setup.exe`.
- Выпуск содержит `SHA256SUMS.txt` для проверки целостности обоих файлов.
- Встроенное обновление Android проверяет подпись APK; Windows updater проверяет
  отдельную криптографическую подпись установщика. Она не заменяет подпись издателя
  Windows Authenticode, предупреждение о которой описано выше.
- Старые выпуски сохранены в Releases.
- Исходный код, аккаунты пользователей и ключи подписи здесь не публикуются.
